# Setup

The SDK works the same way on every chain. You install it, pick the chain
config, and create a client. Everything after that (wallets, sessions,
execution) is the same code.

## Install

```bash
npm install @altananetwork/sdk viem
```

## Choose a chain

```ts
import { createClient, BNB, signerFromPrivateKey } from "@altananetwork/sdk";

const client = createClient({ chains: [BNB] }); // or ETHEREUM, CELO, BNB_TESTNET, CELO_SEPOLIA, BASE_SEPOLIA
const signer = signerFromPrivateKey(process.env.PRIVATE_KEY as `0x${string}`);

const wallet = await client.createWallet({ signer });
console.log(wallet.address);
```

| Config | Chain | Chain id | Fund `wallet.address` with |
| --- | --- | --- | --- |
| `BNB` | BNB Smart Chain (default) | 56 | BNB |
| `ETHEREUM` | Ethereum | 1 | ETH |
| `CELO` | Celo | 42220 | CELO, or USDC, USDT, USDm, EURm or KESm (the relay takes its fee in whichever the wallet holds), plus ETH on Ethereum for Keystore writes |
| `BNB_TESTNET` | BNB Smart Chain Testnet | 97 | test BNB: [faucet](https://testnet.bnbchain.org/faucet-smart) |
| `CELO_SEPOLIA` | Celo Sepolia | 11142220 | test CELO: [faucet](https://faucet.celo.org/celo-sepolia), or test USDC, USDm, EURm or KESm. No Sepolia ETH needed: Keystore writes on Sepolia are funded from this balance |
| `BASE_SEPOLIA` | Base Sepolia | 84532 | Base Sepolia ETH. No Sepolia ETH needed: Keystore writes on Sepolia are funded from this balance |

BNB Smart Chain and Ethereum are L1s: the [Keystore](/concepts/keystore) is
on the chain itself. Celo and Base Sepolia are L2s: the Keystore is on Ethereum (Sepolia on
testnet) and a KeyStoreCache on the L2 mirrors it. The SDK handles the L1 write and the
proof into the cache inside [`grantSession`](/sdk/grant-session) and
[`revokeSession`](/sdk/revoke-session). A wallet that holds no ETH on the L1 still
gets its L1 write: the relay funds it from the wallet's balance on the L2 (on testnet,
one CELO counts as one ETH). A wallet that does hold ETH on the L1 pays there directly. `BASE` is also exported, for the L2
Keystore cache used by [`ensureKeyCached`](/sdk/sync-to-l2).

## Multiple chains

`createClient` accepts several chains. A wallet has the same address on all
of them. Most calls pick one with `chainId`; sessions are granted and revoked
on all of them at once:

```ts
import { createClient, NETWORKS } from "@altananetwork/sdk";

const client = createClient({ chains: [...NETWORKS.mainnet], defaultChainId: 56 });

await client.execute({ /* ... */, chainId: 42220 });      // one chain: Celo
await client.grantSession({ /* ... */ });                  // every chain of the client
await client.grantSession({ /* ... */, chainIds: [56] });  // or only the ones you list
await client.revokeSession({ wallet, signer, session });   // wherever the key lives
```

`NETWORKS.mainnet` is BNB, Ethereum and Celo; `NETWORKS.testnet` is BNB
testnet, Celo Sepolia and Base Sepolia. `networkByChainId(id)` returns the
config for any chain the SDK knows, Sepolia included.
