# Celo Sepolia

Celo Sepolia (chain id **11142220**) is Altana's Celo testnet. The account
contracts and the Altana testnet relay are deployed there, the
[Keystore](/concepts/keystore) is on Sepolia, and a KeyStoreCache on Celo
Sepolia mirrors it (see [Testnet](/concepts/networks/testnet#celo-sepolia)).
The SDK ships a ready-made `CELO_SEPOLIA` config.

## Install

```bash
npm install @altananetwork/sdk viem
```

## Create a wallet on Celo Sepolia

```ts
import { createClient, CELO_SEPOLIA, signerFromPrivateKey } from "@altananetwork/sdk";

const client = createClient({ chains: [CELO_SEPOLIA] });
const signer = signerFromPrivateKey(process.env.PRIVATE_KEY as `0x${string}`);

const wallet = await client.createWallet({ signer });

console.log(wallet.address);
```

**Fund `wallet.address` before step 2:**

| Chain | Asset | Used for | Faucet |
| --- | --- | --- | --- |
| Celo Sepolia | CELO | Relay fees for wallet actions | [faucet.celo.org/celo-sepolia](https://faucet.celo.org/celo-sepolia) |
| Sepolia | ETH | Keystore writes, about 0.0003 ETH each | [Google Cloud Sepolia faucet](https://cloud.google.com/application/web3/faucet/ethereum/sepolia) |

Keystore writes on Sepolia are sent from the wallet's admin key, so the same
address holds both balances. Passkey wallets grant sessions with
`register: false`; the account enforces their permissions and expiry.

## Grant a session

```ts
const session = await client.grantSession({
  wallet,
  signer,
  permissions: { calls: [{ to: "0xDex..." }], spend: [{ limit: 10n ** 18n, period: "day" }] },
  expiry: Math.floor(Date.now() / 1000) + 3600,
});

session.transactionHash; // account authorization on Celo Sepolia
session.registry;        // Keystore write on Sepolia: { chainId: 11155111, status, transactionHash, blockNumber }
session.cache;           // proof into the KeyStoreCache on Celo Sepolia: { chainId: 11142220, status, transactionHash, cachedKey }
```

`grantSession` registers the key in the Sepolia Keystore, authorizes it on the
account through the relay, then proves the Keystore entry into the cache on
Celo Sepolia so any contract or reader there can check it with one `eth_call`.
The last two steps are reported on the result. [`client.syncSessionToCache`](/sdk/sync-to-l2#syncsessiontocache)
runs the proof on its own.

`client.execute({ session, calls })` then runs on Celo Sepolia exactly as on
BNB testnet.

## Revoke a session

```ts
const result = await client.revokeSession({ wallet, signer, session });

result.status;    // account revoke on Celo Sepolia
result.registry;  // Keystore revoke on Sepolia
result.cache;     // proof of the revocation into the cache on Celo Sepolia
```

## Read a session from Celo Sepolia

```ts
import { createPublicClient, http, keccak256 } from "viem";
import { CELO_SEPOLIA, readCachedKey, isCachedKeyValid, keyStoreCacheOf } from "@altananetwork/sdk";

const celo = createPublicClient({ chain: CELO_SEPOLIA.chain, transport: http(CELO_SEPOLIA.publicRpcUrl) });
const keyId = keccak256(session.publicKey);

const entry = await readCachedKey(celo, keyStoreCacheOf(CELO_SEPOLIA), wallet.address, keyId);
// entry.revoked, entry.expiry, entry.isRoot, entry.sourceBlockNumber

const valid = await isCachedKeyValid(celo, keyStoreCacheOf(CELO_SEPOLIA), wallet.address, keyId);
```
