# Celo

Celo (chain id **42220**) is an execution network alongside BNB Smart Chain
and Ethereum. The account contracts and the Altana relay are deployed there,
the [Keystore](/concepts/keystore) is on Ethereum, and a KeyStoreCache on
Celo mirrors it (see [Networks & Addresses](/concepts/networks#celo-celo)).
The SDK ships a ready-made `CELO` config.

## Install

```bash
npm install @altananetwork/sdk viem
```

## Create a wallet on Celo

```ts
import { createClient, CELO, signerFromPrivateKey } from "@altananetwork/sdk";

const client = createClient({ chains: [CELO] });
const signer = signerFromPrivateKey(process.env.PRIVATE_KEY as `0x${string}`);

const wallet = await client.createWallet({ signer });

console.log(wallet.address);
```

**Fund `wallet.address` before step 2:** CELO on Celo for relay fees, and ETH
on Ethereum for Keystore writes. The wallet is provisioned on Ethereum in the
same `createWallet` call, and its Keystore writes go through the relay there.

## Grant a session

```ts
const session = await client.grantSession({
  wallet,
  signer,
  permissions: { calls: [{ to: "0xDex..." }], spend: [{ limit: 10n ** 18n, period: "day" }] },
  expiry: Math.floor(Date.now() / 1000) + 3600,
});

session.transactionHash; // account authorization on Celo
session.registry;        // Keystore write on Ethereum
session.cache;           // proof into the KeyStoreCache on Celo
```

`grantSession` registers the key in the Ethereum Keystore, authorizes it on
the account through the relay, then proves the Keystore entry into the cache
on Celo. `revokeSession` revokes the account, the Keystore entry and the
cache the same way. `client.execute({ session, calls })` runs on Celo exactly
as on BNB.

## Multi-chain

`createClient` accepts multiple wallet execution chains. Add Celo alongside
BNB and pass `chainId` per call:

```ts
import { createClient, BNB, CELO } from "@altananetwork/sdk";

const client = createClient({ chains: [BNB, CELO], defaultChainId: 56 });
await client.grantSession({ /* ... */, chainId: 42220 }); // operate on Celo
```
