# Testnet

Altana's testnet runs on **BNB Smart Chain Testnet (chain 97)** — the full stack
(keystore, account contracts, and the Altana testnet relay) is deployed there, so
you can create wallets and execute end-to-end. The SDK ships a ready-made
`BNB_TESTNET` config, importable from `@altananetwork/sdk`.

The testnet explorer is at [testnet.altana.network](https://testnet.altana.network).

## BNB Smart Chain Testnet: `BNB_TESTNET`

Fund new wallets with test BNB from the
[BNB testnet faucet](https://testnet.bnbchain.org/faucet-smart) before executing.

- **Chain id:** 97
- **Public RPC:** `https://bsc-testnet-rpc.publicnode.com`
- **Explorer:** https://testnet.bscscan.com
- **Faucet:** https://testnet.bnbchain.org/faucet-smart
- **Relay:** `https://testnet-relay.altana.network`
