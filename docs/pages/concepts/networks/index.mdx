# Networks & Addresses

Altana is multi-chain. The SDK ships a config per network, importable from
`@altananetwork/sdk`. **BNB Smart Chain is the default**; Ethereum is
supported for wallet execution and L1 cross-chain proofs; Base is supported as the L2
Keystore cache for cross-chain verification.

Building against testnet? See [Testnet](/concepts/networks/testnet) for BNB
Smart Chain Testnet.

## Supported SDK exports

| Export | Network | Chain ID | Use |
| --- | --- | --- | --- |
| `BNB` | BNB Smart Chain | 56 | Default wallet execution network with a standalone Keystore |
| `ETHEREUM` | Ethereum | 1 | Wallet execution network and L1 Keystore source for cross-chain proofs |
| `BASE` | Base | 8453 | L2 Keystore cache for cross-chain session verification |

## Governance

The KeyStore and KeyStoreController on Ethereum and BNB Smart Chain are owned by a
`TimelockController`, not by an EOA. The minimum delay is 172800 seconds, 48 hours, so any
privileged change is queued and visible onchain for two days before it can execute.

| Role | Address | Chains |
| --- | --- | --- |
| TimelockController | `0x538F7e830AAefF9CFcdDB3a66A6DF67Cc4FD466B` | Ethereum |
| TimelockController | `0xB8A02c99176c58D49747ed4f42b4e5DB3684da2D` | BNB Smart Chain |
| Admin Safe (proposer) | `0x83Ee9c976389A6D708504490eFf2DAfC665637B6` | Ethereum, BNB Smart Chain |
| Treasury Safe | `0x779faCC9cA0e5D07F70eEfe26A33D579c04cc38e` | Ethereum, BNB Smart Chain |

The admin Safe holds `PROPOSER_ROLE` on both timelocks and is separate from the treasury Safe.
Both are Safe multisigs at a 4 of 6 threshold.

Nothing here needs to be taken on trust. Check it yourself:

```bash
# 48 hour delay
cast call 0x538F7e830AAefF9CFcdDB3a66A6DF67Cc4FD466B "getMinDelay()(uint256)" \
  --rpc-url https://ethereum-rpc.publicnode.com

# KeyStore is owned by the timelock
cast call 0xb70fDa90C1d576Ba8399946a0c10ECD9d9Ea923b "owner()(address)" \
  --rpc-url https://ethereum-rpc.publicnode.com

# Safe threshold
cast call 0x83Ee9c976389A6D708504490eFf2DAfC665637B6 "getThreshold()(uint256)" \
  --rpc-url https://ethereum-rpc.publicnode.com
```

Base runs `KeyStoreCacheOPStack`, which mirrors the Ethereum Keystore through OP Stack state
proofs rather than holding its own privileged roles.

> Addresses are the source of truth in the Keystore repo's deployment manifests
> (`deployments/*.json`) and the SDK's `packages/wallet/src/config.ts`. If contracts are
> redeployed, update both in lockstep.
