# Acknowledgments

The Altana SDK builds on [Porto](https://porto.sh) (MIT), extended for Keystore compatibility. Credit to the Porto team for that work.

Altana maintains the stack it runs: we operate it in production on Ethereum, BNB Chain and Base, and the layers you integrate against are ours. The SDK imports `porto` as a pinned dependency rather than forking it, so the surface you build on is one we control.
