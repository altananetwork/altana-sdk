# Acknowledgments

Altana Keystore sits on top of wallet infrastructure: smart accounts, session keys, relayers, validator hooks.

For the EVM ecosystem, [**Porto Wallet**](https://porto.sh) is the best implementation of wallet infrastructure we've tested, and the Altana SDK was built on top of it with our own modifications to have Keystore compatibility. Thanks to the Porto team for the work that made this possible.
