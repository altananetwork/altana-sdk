@altana/wallet · SDK reference demo

Generate passkey wallets connected to the KeyStore

A TypeScript SDK for passkey-secured smart-account wallets. Integrators ship biometric wallet creation, on-chain scoped session keys for AI agents, and passkey-driven recovery through the Altana KeyStore registry — all from a single library.

main.ts TypeScript · @altana/wallet 
import {
  createPasskeyWallet,
  grantSession,
  execute,
  revokeSession,
  recoverFromPasskey,
} from "@altana/wallet"
import { parseEther } from "viem"

// 1. Create wallet — passkey is the only authority
const wallet = await createPasskeyWallet({
  name: "My App Wallet",
})

// 3. Grant a scoped session key to an agent.
//    On the wallet's first admin action, the SDK auto-prepends
//    KeyStore.initialRegisterKey into the same tx — one userOp,
//    two state changes. That's what makes recovery work later.
const session = await grantSession(wallet, wallet.signer, {
  permissions: {
    calls: [{ to: recipient }],
    spend: [{ limit: parseEther("0.01"), period: "day" }],
  },
  expiry: Math.floor(Date.now() / 1000) + 3600,
})

// 4. Agent executes within scope (no biometric)
await execute(session, {
  to: recipient,
  value: 1n,
  data: "0x",
})

// 5. Revoke when done
await revokeSession(wallet, wallet.signer, session)

// Lost localStorage? Passkey alone recovers the wallet.
const restored = await recoverFromPasskey()

Grant a session key to an agent

grantSession(wallet, admin, { permissions, expiry })

A session key is a separate key the wallet authorizes to act on its behalf — within rules. Anything outside the rules reverts at the smart-account contract. Set the rules below, then sign the grant with your passkey.

This session will be allowed to:
  • Send ETH only to (set recipient)
  • Spend at most 0.01 ETH per rolling 24h window
  • Expire after 1 hour
Anything outside these rules — different recipient, over the cap, after expiry — fails at the wallet contract. The session key cannot escape its scope.

What you just used

        

          

            createPasskeyWallet
            One call. Generates the throwaway EOA, prompts WebAuthn, runs EIP-7702.
          

          

            grantSession
            Authorizes a scoped key on-chain. Allow-listed calls + spend caps + expiry.
          

          

            execute
            Polymorphic. Admin signs, or session signs — same function.
          

          

            revokeSession
            Single tx. Effect is immediate at the smart-account contract.
          

          

            recoverFromPasskey
            WebAuthn picker + two eth_calls to KeyStore. No backend involved.
          

          

            signerFromPrivateKey / createHeadlessPasskey
            For agent servers + tests. Same SDK surface, no browser needed.
